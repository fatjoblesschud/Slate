
# Slate
Slate is a minimal, notes app without distractions.
Every note is saved locally, meaning your notes are 100% private without any chance of someone else reading your notes, if you did not show it to them yourself. Slate also contains a code editor which allows you to write in different programming languages such as Python , C+ , Rust and many more.
